# Book Info Website (Frames)

A simple book information site using HTML frames.
Left side shows the book list, right side shows details.

## Files
- `index.html` — home page (frameset)
- `books.html` — left frame, book list
- `info.html` — right frame, default message
- `book1.html` to `book5.html` — right frame, book details

## Run
Open `index.html` in a browser.

## Deploy (GitHub Pages)
1. Upload all files to repo root
2. Settings → Pages → Source: main branch, root
3. Visit the generated link
